The experiment

One path is not the distribution.

A hard alignment picks a minimum-cost path. Soft-DTW gives every legal path Gibbs weight exp(-cost / temperature). Higher temperature admits more expensive paths; it does not make the raw score a distance.

Raw soft-DTW can be negative, including on identical sequences. Cell occupancies sum to the expected path length, not one. They are not a transport coupling.

The supplied controls are synthetic demonstrations, not accuracy benchmarks. Established algorithms are credited below. WarpLab adds an inspector and independent bounded verification, not a new alignment method.

Forward / backward / covariance

The complete alignment

Rows are X samples, columns are Y samples. Select a cell to inspect its incoming and outgoing probability. A border marks the selected complete path.

Cell and edge inspector

Each edge shows joint probability of traversing that edge, not a conditional transition probability. Incoming and outgoing flows equal the cell occupancy, except at the endpoints.

Sequence gradients

Gradients are for the raw soft-DTW score using squared local costs. The displayed Hessian product is with respect to independent cost entries, not sequence coordinates.

Follow a complete path

All paths include both endpoints and use right, down, or diagonal moves. The order is deterministic, not a ranking by probability. Hard ties compare exact sums of the binary64 local costs; one lexicographically first minimizer is drawn.

Numerical certificate and identities
Temperature derivative = -path entropy. Cost Hessian = -Cov(path incidence) / temperature, so curvature in any cost direction is nonpositive. Binary64 rounding and underflow can produce tiny residuals or zero probabilities. No automatic-differentiation package is used.
Small enough to check every path.
The main engine uses stable log-space forward/backward messages and directional expectation messages in O(nm). The Python verifier enumerates every legal path, evaluates Gibbs probabilities directly after minimum-cost centering, then checks every reported occupancy, edge flow, gradient and covariance product. The largest admitted grid has 8,989 paths.
This is an unconstrained monotone-path model. No window constraint, multivariate input, learned metric, training claim, or production performance claim. Raw soft-DTW is not a metric. The self-corrected divergence is deliberately not implemented: nonnegativity theorems in the 2021 paper depend on the ground cost and must not be borrowed without their assumptions.
